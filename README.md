# Academic Portfolio

A responsive, single-page academic portfolio website that can be hosted on GitHub Pages. It uses plain HTML and CSS, so there is no build step or dependency installation.

## Personalize your page

Edit `index.html` and replace the bracketed prompts, such as `[Your Name]`, `[Institution name]`, and `[2024 — Present]`, with your own details. Update the email address, LinkedIn URL, study timeline, achievements, and interests. Remove any education or highlight cards you do not need, or duplicate one to add another entry.

The profile photo area is currently a styled initials placeholder. You can replace the `<div class="avatar-placeholder">` in `index.html` with an image and add your image file to this repository.

## Preview

Open `index.html` directly in a browser, or use a local development server. The page is responsive and includes a small inline script to display the current year in the footer.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. After GitHub Pages finishes deploying, the site URL will appear in the Pages settings.

The Google Fonts import is optional; the page falls back to system fonts if those fonts cannot be loaded.
